## Live preview

One document, not two.

Every other editor makes you choose: read the Markdown or read the result. Lumen shows you the result and hands back the source only where you are working.

## Beyond paragraphs

Tables that look like tables.

Pipe tables render as real tables, right down to column alignment — click any row to drop the caret on its source line. LaTeX renders through KaTeX both inline and as display blocks. Fenced code becomes a card with a language chip and highlighting for over a hundred languages.

Images resolve against the document's own folder, so a note you wrote three years ago still shows its pictures.

## Themes

Eleven of them. Try one on this page.

Five light, six dark. Each one restyles the whole editor — chrome, text, code syntax and highlight marks. Pick a light theme and a dark theme, and let the mode follow your system.

Every palette is checked for contrast: body and secondary text clear the WCAG AA threshold of 4.5:1 on all eleven.

    These are the editor's real palettes — the page is wearing them too.

    ## The rest of it

    Details you only notice when they are missing.

    • Right-click knows what you clicked

      On a table you get insert and delete row or column, move row, and column alignment — and the pipes re-align themselves afterwards. On a link, open or edit the address. On a code block, copy it without the fences.

    • Writes where you told it to

      Auto-save runs 1.5 seconds after you stop typing. Windows line endings are detected on open and restored on save. Deletes go to the system trash.

    • Notices edits from elsewhere

      Change a file in another program and Lumen spots it when the window regains focus, asking which version wins if your buffer is dirty.

    • Focus and typewriter modes

      Dim everything except the paragraph you are in, and pin the caret at a fixed height so the page scrolls under you rather than the caret sinking.

    • Your folder, your files

      A file tree, a live outline, and full-text search across the folder. Plain .md on disk, no database, no sync account, no lock-in.

    • Takes the document with you

      Export a self-contained HTML file with the styling baked in, or print straight to PDF with print-specific typography.
